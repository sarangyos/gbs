# GBS 아이스브레이킹

GBS 모임 시작할 때 폰 하나로 쓰는 아이스브레이킹 도구입니다. 나눔 질문 뽑기, 밸런스 게임, 성경 초성 퀴즈, 첫 순서 뽑기와 나눔 타이머가 들어 있습니다. 파일은 `index.html` 하나로 끝나서 따로 설치할 것이 없습니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. 무료 계정이라면 Public으로 만들어야 Pages를 쓸 수 있습니다.
2. 저장소 화면에서 Add file → Upload files로 `index.html`(과 이 README)을 올리고 Commit 합니다.
3. Settings → Pages로 가서 Source를 "Deploy from a branch", Branch를 `main` / `(root)`로 두고 Save 합니다.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소로 열립니다.

조원들에게는 이 주소만 공유하면 되고, 폰 브라우저의 "홈 화면에 추가"를 쓰면 앱처럼 열 수 있습니다.

## 질문이나 문제 고치기

`index.html`을 열면 스크립트 윗부분에 "내용 수정은 여기서부터"라고 표시된 곳이 있습니다. 나눔 질문(`QUESTIONS`), 밸런스 게임(`BALANCE`), 초성 퀴즈(`QUIZ`), 첫 순서(`ORDER`), 타이머 시간(`PRESETS`)이 전부 거기 모여 있습니다. 따옴표와 쉼표 형식만 지키면서 줄을 추가하거나 지우면 되고, 초성은 정답을 넣으면 자동으로 만들어집니다. GitHub 웹에서 파일을 열고 연필 아이콘으로 바로 수정해도 몇 분 안에 사이트에 반영됩니다.

## 참고

앱 안의 "내 질문 추가"로 넣은 질문은 그 기기 브라우저에만 저장됩니다. 조원 모두가 같이 봐야 하는 질문이라면 위 방법대로 `index.html`에 직접 넣어 주세요.

나눔 타이머는 끝나면 소리와 진동으로 알려 줍니다. 아이폰은 무음 모드에서 소리가 나지 않을 수 있습니다.
